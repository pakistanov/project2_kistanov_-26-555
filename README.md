# Primitive DB

Учебная консольная база данных на Python 3.12 и новее.

## Установка и запуск

Из корня проекта:

```powershell
uv sync
uv run database
```

Сборка и установка отдельного CLI-инструмента:

```powershell
uv build
uvx twine check dist/*
uv tool install --force --link-mode copy .\dist\primitive_db-0.3.0-py3-none-any.whl
database
```

Если папка инструментов отсутствует в PATH, выполните `uv tool update-shell`
и откройте новый терминал. Команда `project` также поддерживается.

## Управление таблицами

| Команда | Действие |
| --- | --- |
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать имена таблиц |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Завершить работу |

Поддерживаемые типы: `int`, `str`, `bool`. Имена таблиц и столбцов должны быть
допустимыми идентификаторами Python: например, `users`, `is_active`, `товары`.
Повторяющиеся столбцы запрещены. Столбец `ID:int` всегда стоит первым:
если он не указан, программа добавит его; явно указанный `ID:int` не дублируется.

Пример сеанса:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: exit
```

Структура таблиц сохраняется в `db_meta.json` в текущей рабочей папке.
При повторном запуске из той же папки таблицы сохраняются.
Этот файл хранит имена таблиц и типы столбцов:

```json
{
    "users": ["ID:int", "name:str", "age:int", "is_active:bool"]
}
```

Повреждённый JSON вызывает сообщение об ошибке и завершение программы,
чтобы не перезаписать существующие данные.

## CRUD-операции

CRUD — добавление, чтение, обновление и удаление записей.
Записи хранятся в `data/<имя_таблицы>.json` в текущей рабочей папке.
Файл создаётся при создании таблицы и удаляется вместе с ней.

| Команда | Действие |
| --- | --- |
| `insert into <имя> values (<значение1>, ...)` | Добавить запись |
| `select from <имя>` | Показать все записи |
| `select from <имя> where <столбец> = <значение>` | Найти записи по условию |
| `update <имя> set <столбец> = <значение> where <столбец> = <значение>` | Обновить записи |
| `delete from <имя> where <столбец> = <значение>` | Удалить записи по условию |
| `info <имя>` | Показать структуру и количество записей |

Все поля обязательны. В `insert` значения перечисляются в порядке столбцов,
без ID. Новый ID равен максимальному существующему ID плюс один;
для пустой таблицы он равен 1.

Строки обязательно заключаются в двойные или одинарные кавычки, числа
вводятся без кавычек, логические значения — `true` и `false`.
Например, `28` — число, а `"28"` — строка. Поддерживаются только условия равенства.
Можно обновить несколько полей, разделив присваивания запятыми.
При изменении ID он должен оставаться положительным и уникальным.

```text
create_table users name:str age:int is_active:bool
insert into users values ("Sergei", 28, true)
select from users
select from users where age = 28
update users set age = 29 where name = "Sergei"
delete from users where ID = 1
info users
exit
```

`select` выводит результат через PrettyTable. Изменения сохраняются в JSON
и доступны после перезапуска из той же папки.
